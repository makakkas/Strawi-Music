# Strawi Music

<p align="center">
  <b>Tu música. Tu interfaz. Tu manera.</b>
</p>

Strawi Music es un launcher de música de escritorio gratuito, libre y de código abierto, creado con la idea de ofrecer una experiencia musical mucho más personalizable que un reproductor tradicional.

El proyecto integra APIs y servicios relacionados con YouTube y YouTube Music para permitir buscar, descubrir, organizar y reproducir música desde una interfaz propia.

Strawi Music no busca limitar al usuario a una sola apariencia o forma de utilizar la aplicación. La idea es entregar un launcher que pueda adaptarse a cada persona mediante temas, extensiones, CSS personalizado, diferentes diseños de reproductor y herramientas adicionales.

> Strawi Music actualmente se encuentra en desarrollo.
> Próximamente habrá una versión pública disponible.

## ¿Qué es Strawi Music?

Strawi Music es un launcher de música para escritorio que utiliza el catálogo disponible a través del ecosistema de YouTube y YouTube Music.

A diferencia de una aplicación de música tradicional, Strawi Music está pensado como una plataforma personalizable sobre la cual se pueden agregar nuevas funciones, diseños, temas y extensiones.

El proyecto busca ser:

- 🆓 Completamente gratuito
- 🔓 De código abierto
- 🎵 Enfocado completamente en la música
- 🎨 Altamente personalizable
- 🖥️ Diseñado principalmente para escritorio
- 🧩 Extensible mediante temas y extensiones
- 💾 Capaz de mantener configuraciones y funciones locales
- 🌎 Accesible para cualquier persona

No existen versiones Premium de Strawi Music ni funciones bloqueadas detrás de un pago.

La idea es que todo lo que forme parte del launcher pueda utilizarse gratuitamente.
